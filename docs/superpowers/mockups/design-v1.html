Дизайн бота «Deye Home» в Telegram — v1

Это то, как сообщения реально будут выглядеть (Telegram умеет: жирный, моноширинный блок, цитату-плашку, кнопки под сообщением). Цифры для примера.

Главные принципы удобства

  • Одна «панель», а не лента сообщений. Кнопки не шлют новые сообщения — они перерисовывают ту же панель. Чат не засоряется.
  • Первая строка = суть. В пуше на экране блокировки видно только начало — поэтому там сразу «🔴 Свет пропал · 04:17».
  • Громко — только важное. Свет пропал/вернулся и низкий заряд — со звуком. «Нет данных от Deye» — тихо. Статистика — только по кнопке.
  • Всегда видно, насколько данные свежие («обновлено 2 мин назад»).
